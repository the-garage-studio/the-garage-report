# The Garage Report

## **Introducción**
Este proyecto nace de una idea que tenía en mente desde hace tiempo. Crecí jugando FIFA y uno de los diferenciales de este juego que más me llamaba la atención era el mercado de transferencias. Basicamente consistia en una dinámica de comprar, vender y coleccionar jugadores únicos. A partir de esa idea surgió este proyecto, que es un mercado de cartas de carros, donde cada carta representa un modelo de carro único e irrepetible, similar a una carta coleccionable. El usuario va a poder decidir que hacer con su carta, ya sea si la quiere vender o coleccionar y lo más importante **LAS CARTAS SON ÚNICAS**.

La temática de carros fue una elección intencional, donde quería tener una excusa para aprender más sobre modelos, marcas y características del mundo automotriz, mientras desarrollaba un proyecto que combinara algo que me motivara con la oportunidad de fortalecer y demostrar habilidades técnicas como desarrollador backend y como ingeniero de software.

Este proyecto no busca solucionar un problema en específico, sino realizar una idea que tenía desde hace tiempo y con lo que he aprendido durante la carrera ahora sí lo puedo realziar siguiendo buenas prácticas y demostrando de que algo que aprendo lo puedo aplicar. 


## **Visión**

El proyecto busca convertirse en una plataforma funcional de intercambio de cartas de carros, replicando una experiencia similar a la de un mercado de transferencias tipo FIFA, pero aplicada a una temática automotriz.
Asimismo, el desarrollo de este proyecto tiene como propósito personal y profesional demostrar dominio en:

* Diseño y diagramación de arquitectura mediante el modelo C4
* Desarrollo backend con Java y Spring Boot, aplicando DDD y patrones de diseño
* Automatización de despliegues con GitHub Actions
* Despliegue en la nube utilizando Azure
* Contenerización de la aplicación con Docker
Dimensionamiento y estimación de costos de infraestructura en un entorno productivo
